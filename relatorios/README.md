# Relatórios

| Diretório | Cadência | Conteúdo |
| --------- | -------- | -------- |
| `diarios/` | A cada execução do monitoramento | Novos registros, atualizações, prazos críticos, divergências entre fontes, pendências e checklist de validação |
| `semanais/` | Segundas-feiras | Consolidação da semana: editais publicados, mudanças de status, alterações de prazo e de quadro de vagas |
| `mensais/` | Primeiro dia útil do mês | Panorama do mês, evolução dos previstos/autorizados e balanço dos certames encerrados |

Nomeie os arquivos por data: `diarios/AAAA-MM-DD.md`, `semanais/AAAA-Snn.md`
(semana ISO), `mensais/AAAA-MM.md`.

Cada relatório deve deixar explícito **o que foi adicionado, alterado ou
encerrado** e apontar as divergências entre fontes que ficaram sem solução —
esses dois pontos são o que torna o relatório auditável depois.

Relatórios antigos não são apagados nem reescritos: eles são o registro do que se
sabia em cada data.
